# Support

Use the following channels:

- Bug report: open a GitHub issue with the bug template.
- Feature request: open a GitHub issue with the feature template.
- Usage question: open a GitHub Discussion when discussions are enabled.
- Security issue: follow `SECURITY.md` instead of opening a public issue.

Please include:

- operating system
- release version or commit hash
- startup command
- whether you use `icloud.com` or `icloud.com.cn`
- sanitized error output

Do not include Cookie values, App-specific passwords, `data/accounts.json`, or `data/create_jobs.json`.
